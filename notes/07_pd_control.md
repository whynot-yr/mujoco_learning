# v0.7 PD Control

## 1. 什么是开环控制，什么是闭环控制

- 开环控制：先给一个输入，然后不看当前状态，只让系统自己跑
- 闭环控制：每一步都先看当前状态，再重新计算输入

固定 `data.ctrl = 常数` 就是很典型的开环控制；PD 控制器则是闭环控制。

## 2. 固定 data.ctrl 和 PD controller 的区别

固定 `data.ctrl` 时：

- 输入不会根据误差变化
- 系统偏了也不会自动纠正

PD controller 时：

- 当前角度离目标越远，控制器会根据误差自动调节
- 当前速度太大时，控制器也会加入阻尼项抑制振荡

## 3. PD 控制公式

常见形式是：

```text
ctrl = kp * error - kd * velocity
error = target - current
```

这里：

- `kp` 是比例增益
- `kd` 是微分增益

## 4. P 项和 D 项分别有什么作用

P 项：

- 根据当前位置误差产生控制
- 误差越大，控制通常越强

D 项：

- 根据当前速度产生阻尼效果
- 速度太大时，D 项会帮助系统“刹车”

直观上：

- 只有 P，可能会来回摆动
- 加上 D，通常会更稳一些

## 5. 为什么 ctrl 要 clip

因为 actuator 往往有输入上限。

如果不限制：

- 控制量可能大得不合理
- 数值可能更容易发散
- 也不符合真实执行器的能力边界

所以常见做法是把 ctrl 裁剪到一个区间，比如 `[-2, 2]` 或 `[-3, 3]`。

## 6. 为什么 PD 控制是机器人控制中非常基础但重要的概念

因为它很简单，但已经包含了机器人控制里非常关键的闭环思想：

- 读取当前状态
- 和目标比较
- 根据误差重新施加控制

很多更复杂的控制器，都是在这个思路上继续发展出来的。先把 PD 真正看懂，后面学力矩控制、轨迹跟踪、状态反馈、MPC 或 RL 都会更顺。
